# David Dada Babatunde — Portfolio

## Run locally
1. Extract the `Dada-Portfolio` folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, colours, responsive design and animations
- `script.js` — mobile navigation, reveal effects, typing animation and email copy button
